## 📖 О проекте

Персональная онлайн-галерея сертификатов, дипломов, свидетельств и удостоверений о повышении квалификации, а также список научных трудов. Сайт состоит из двух страниц:

- **`index.html`** — сертификаты и удостоверения,
- **`articles.html`** — научные публикации.

Данные хранятся в репозитории (папки `certificates/` и `articles/`), а страницы читают локальные манифесты `certificates.json` и `articles.json`. **Новые файлы появляются на сайте без правки JS** — достаточно положить файл в папку и добавить одну запись в манифест.

Страница выдержана в медицинской палитре: глубокий синий, бирюзовый акцент, сине-серые плашки. Поддерживает светлую и тёмную темы автоматически по системным настройкам.

## ✨ Возможности

| | Возможность | Описание |
|---|---|---|
| 🗂 | **Манифесты** | Файлы читаются по локальным `certificates.json` / `articles.json`. Добавили запись → она сразу на сайте. |
| 🖼 | **Поддержка форматов** | JPG, JPEG, PNG, WebP, GIF, JFIF, BMP и PDF. |
| 📄 | **Полноценный PDF-просмотр** | В модальном окне через PDF.js рендерятся **все** страницы документа в виде «листов бумаги». Без новых вкладок. |
| 🪟 | **Модальные окна** | Единый просмотрщик для сертификатов и статей. Просмотр изображений и PDF без перехода со страницы. |
| 🎛 | **Фильтры** | По году и специальности. С подсчётом часов обучения на каждой кнопке. |

| 🌗 | **Единая тема** | Светлая и тёмная тема для обеих страниц. Без «вспышки» при загрузке (anti-FOUC) — инлайновый скрипт ставит тему до первой отрисовки. |
| ⬆️ | **Кнопка «Наверх»** | И на странице, и внутри модалки (появляется при прокрутке). |
| 📱 | **Адаптивность** | 3 колонки на десктопе, 2 на планшете, 1 на телефоне. |
| 🗓 | **Сортировка по дате** | Новые записи — сверху. |
| 🇷🇺 | **Русские названия и метаданные** | Задаются через словари `TITLES`, `META`, `HOURS`, `SPECIALTIES`, `CERT_SPECIALTY`. |

## 🧩 Как это работает

### Сертификаты (`index.html`)

1. `script.js` запрашивает `certificates.json`.
2. По каждой записи строится карточка (PDF или изображение).
3. Работают фильтры по году и специальности; сумма часов на кнопках фильтров пересчитывается под выбранное подмножество.
4. Клик по карточке открывает модалку: изображение — `<img>`, PDF — заглушка с кнопкой «Открыть PDF» (GitHub блокирует встраивание PDF в iframe).

### Публикации (`articles.html`)

1. `script.js` запрашивает `articles.json`.
2. По каждой записи строится карточка с типом (PDF / IMG / ССЫЛКА).
3. Клик по карточке открывает модалку:
   - **PDF** → все страницы рендерятся через PDF.js в `<canvas>`;
   - **IMG** → просто изображение;
   - **внешняя ссылка** → открывается в новой вкладке (`target="_blank"`), модалка не перехватывает клик.
4. Слева — «Путь в науку» (жизненный цикл публикаций 1996 → 2010), клик по маркеру открывает модалку с описанием работы.

### Темы и anti-FOUC

В `<head>` обеих страниц стоит маленький инлайновый скрипт, который выставляет `data-theme` на `<html>` **до** применения CSS. Это исключает «мигание» светлой темы при загрузке, если у пользователя сохранена тёмная.

## 🚀 Быстрый старт

### Клонирование репозитория

```bash
git clone https://github.com/NatalyaSvetlakova/ns-medical-profile.git
cd ns-medical-profile
```

Откройте `index.html` или `articles.html` в браузере — сервер не нужен, всё работает как статические файлы.

> ⚠️ Если браузер блокирует `fetch('certificates.json')` из-за `file://`, поднимите локальный сервер: `python -m http.server 8000` или через расширение Live Server в VS Code.

## 📝 Добавление нового сертификата

1. Файл в `certificates/`.
2. Запись в `certificates.json`:
   ```json
   { "name": "2026.10.10.pdf", "url": "certificates/2026.10.10.pdf" }
   ```
3. Подпись и метаданные в `script.js`:
   - `TITLES['2026.10.10']` — заголовок карточки;
   - `META['2026.10.10']` — «кто выдал · год»;
   - `HOURS['2026.10.10']` — часы обучения;
   - `CERT_SPECIALTY['2026.10.10']` — ключ специальности из `SPECIALTIES`.

---

## 📝 Добавление новой публикации

1. PDF в `articles/` (или внешняя ссылка).
2. Запись в `articles.json`:
   ```json
   {
     "title": "Название статьи",
     "date": "2024-05-01",
     "url": "articles/название.pdf",
     "image": "articles/images/название.jpg",
     "description": "Короткое описание"
   }
   ```
3. Для внешней ссылки — `"external": true`:
   ```json
   { "title": "...", "date": "2024-05-01", "url": "https://...", "external": true }
   ```
